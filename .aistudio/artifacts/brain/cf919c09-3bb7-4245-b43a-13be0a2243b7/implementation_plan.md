# 自习室自律学习区（Zen Study Space）极简灵动重构方案

以 Apple Human Interface Guidelines（macOS StandBy 待机显示与 Apple Music 流体律动）为设计标杆，彻底重构工具区中的「自习室自律学习区」。化繁为简，剔除冗余的自定义混音滑块、游戏化勋章墙与说明卡片，聚焦于**丝滑舒缓的双模音乐律动、全屏时钟与番茄钟同屏交互、弹性跳动数字动画、三款精选场景化白噪音预设**以及极低性能负载的 60fps 灵动体验。

---

## 用户决策确认与核心范围

> [!IMPORTANT]
> 以下为第一阶段确认的核心产品与设计决策，将在本次重构中严格执行：

- **确认决策 1 — 音乐律动效果精简与重塑**：仅保留并深度打磨 **「流光丝绸波浪（Fluid Silk Waves）」** 与 **「禅意呼吸光环（Breathing Halo Ring）」** 两套律动效果，采用二阶阻尼平滑算法消除音频频谱抖动，使节奏缓和、灵动且具备呼吸感。
- **确认决策 2 — 白噪音化繁为简（3 款场景预设）**：移除原有的 5 路自定义滑块混音工坊与空灵合成器开关，改为一键切换的 3 个高保真 Web Audio 场景化白噪音预设：**「深度专注 · 听雨（Deep Focus Rain）」**、**「静心阅读 · 营火（Reading Campfire）」**、**「舒缓小憩 · 海风（Rest Ocean Breeze）」**。
- **确认决策 3 — 外围面板精简与音源保留**：移除 12 枚勋章墙与长篇文字指南卡片，保留实用的 **本地音频导入（MP3/WAV 伴读）** 与 **麦克风/系统音频拾音**，整体界面清爽克制，契合个人摄影与极简实用作品集的基调。
- **确认决策 4 — 全屏显示与图层叠加控制**：支持一键进入全屏模式（Browser Fullscreen API + 沉浸式视口兜底），全屏下支持**实时系统时钟 + 番茄倒计时**同屏或主次切换、随时快捷调整倒计时时长，并提供独立的图层控制开关——**可同时叠加展示「全屏时钟 + 音乐律动」，也可单独只开「纯享时钟」或「纯享律动」**。

## 1. 核心概念与体验升级

- **核心定位**：打造一个零干扰、高颜值的桌面级伴学与专注空间。无论是日常浏览还是全屏放置在桌面一角作为 StandBy 伴学时钟，都能提供赏心悦目的光影呼吸感与清晰的时间感知。
- **核心价值**：
  - **视觉降噪**：告别杂乱的多栏仪表盘和机械式跳动频谱，用大留白、圆润毛玻璃控制器与丝滑物理弹簧过渡呈现高级秩序感。
  - **全屏伴学实用性**：全屏状态下同时兼顾「当前现实时间（HH:MM:SS）」与「番茄钟倒计时」，无需退出全屏即可随时微调时长（+5/-5 分钟、预设切换、启停重置）。
  - **高性能低功耗**：Canvas 渲染采用动态 DPR 限制、离屏渐变缓存与低通惯性滤波，即使全屏长时间挂机也不会引起设备发烫或掉帧。

## 2. 用户体验与视觉设计（Apple 灵动美学）

### 核心用户流程
1. **进入自修室**：映入眼帘的是居中舒展的主舞台卡片（Stage Deck）与底部悬浮式灵动控制栏（Floating Control Bar），不再有左右割裂的繁琐侧边栏。
2. **开启白噪音或外部音源**：点击底部或胶囊区的三款场景白噪音（「深度专注 · 听雨」、「静心阅读 · 营火」、「舒缓小憩 · 海风」），声音以 0.8 秒指数包络柔和淡入；也可一键导入本地音乐或开启系统拾音。
3. **调整时钟与番茄钟**：在主舞台可随时查看当前系统时间与番茄倒计时，支持快速切换 `25m 专注` / `45m 深度` / `5m 休息` 或通过 `-5m` / `+5m` 微调时长，每位数字变化均触发 Apple 风格的物理弹簧翻滚跳动（Spring Digit Roll）。
4. **全屏沉浸模式（Fullscreen StandBy）**：
   - 点击右上角「进入全屏」按钮，平滑展开至全屏画布。
   - 全屏视图中央呈现超大号 tabular-nums 现代极简时钟与番茄钟胶囊，支持直接点击加减时间、暂停/继续。
   - 底部悬浮控制条支持鼠标静止 3 秒后自动优雅隐退（唤醒即显），内含 **显示图层切换（时钟 + 律动叠加 / 仅时钟 / 仅律动）**、**律动样式切换（流光丝绸 / 呼吸光环）** 与 **3 款白噪音场景切换**。

### 视觉规范与主题适配
- **美学基调**：Apple macOS Sonoma / iOS StandBy 现代极简风格，柔和的半透明毛玻璃（`backdrop-blur-2xl`）、1px 细腻高光描边、无冗余徽章。
- **色彩与对比度（60-30-10 法则）**：
  - **60% 纯净画布**：自动适配网站亮/暗色与主题色变量（`--theme-bg`），全屏模式下提供深邃静谧的暗色沉浸底幕或跟随系统主题。
  - **30% 结构层与毛玻璃容器**：采用 `--theme-card` 与细腻的 `--theme-border`，保证单一卡片层级（不嵌套多层边框卡片）。
  - **10% 灵动焦点色**：严格使用 `--brand-color`（`accent`）点亮当前激活的白噪音场景、番茄钟进度弧与律动主光晕。
- **字体与数字排版**：
  - 时钟与倒计时严格启用等宽数字特性（`tabular-nums tracking-tight`），确保秒数跳动时水平宽度绝对稳定、零抖动。
  - 摒弃全大写机械前缀与装饰性脉冲绿点，采用自然克制的中英混排标题。
- **Apple 级物理弹簧动画（Motion Specs）**：
  - **数字跳动（Spring Tick）**：每位数字独立拆分，数字更替时沿着垂直轴向带轻微高斯模糊与弹性阻尼过渡（`type: "spring", stiffness: 320, damping: 28, mass: 0.8`）。
  - **控制栏展开与隐退**：使用 `cubic-bezier(0.16, 1, 0.3, 1)` 与 `layoutId` 共享布局动画，选中态滑块如 iOS 分段控制器般丝滑滑动。

## 3. 关键产品与技术决策

- **决策 1：双律动引擎的缓和化与性能优化**
  - *方案*：
    1. **流光丝绸（Fluid Silk Waves）**：使用 3 层三次贝塞尔曲线（Cubic Bezier）构建低频缓慢流动的丝绸波浪，采样音频低中频能量并通过 `0.93` 惯性系数滤波，杜绝生硬折线与高频闪烁。
    2. **呼吸光环（Breathing Halo Ring）**：以中心柔光球体配合连续极坐标闭合样条曲线，随音频振幅做慢速径向呼吸与微弱相位旋转。
  - *原因*：用连续数学曲线取代密集的粒子或柱状频谱，既贴合自习室安静舒缓的心理暗示，又将 Canvas 每帧绘制指令减少 75% 以上，大幅降低 GPU/CPU 占用。
- **决策 2：预设化白噪音合成器（零外部音频依赖）**
  - *方案*：基于 Web Audio API 实时合成 3 款场景预设，无需加载庞大音频文件，且切换时采用 `setTargetAtTime` 实现丝滑交叉淡入淡出（Crossfade）：
    1. **深度专注 · 听雨**：粉红/白噪声混合双二阶带通滤波 + 柔和低频水滴包络。
    2. **静心阅读 · 营火**：暖色粉红噪声低通基底 + 随机微弱木柴轻响脉冲。
    3. **舒缓小憩 · 海风**：布朗噪声配合 0.07Hz 超慢速正弦 LFO 调制滤波器截止频率，模拟自然海浪潮汐呼吸。
- **决策 3：全屏模式下「时钟/番茄钟」与「音乐律动」自由组合**
  - *方案*：引入 `displayLayerMode: "both" | "clockOnly" | "visualOnly"` 状态：
    - 当选择 `both`（叠加）时：底层渲染柔和降噪的音乐律动 Canvas，上层居中悬浮高对比度全屏时钟与番茄钟。
    - 当选择 `clockOnly`（仅时钟）时：暂停 Canvas 帧循环（零 GPU 渲染开销），仅展示纯净的翻页跳动大时钟与番茄钟。
    - 当选择 `visualOnly`（仅律动）时：隐藏中央大时钟，让流光丝绸或呼吸光环完整占据全屏视口，顶部保留微型时间胶囊提示。

### 交互与状态映射关系
- **实时时钟与番茄钟切换/同屏**：
  - 主舞台同时显示「当前时间（系统实时秒级更新）」与「番茄钟倒计时」，可通过顶部分段控制器切换主视觉焦点（以「番茄钟为主、实时时间为辅」或「实时大时钟为主、番茄钟胶囊为辅」），全屏下两者均清晰可读。
- **倒计时即时微调**：
  - 无论处于普通模式还是全屏模式，用户均可直接点击 `-5m` / `+5m` 按钮或预设时长标签（`25m`、`45m`、`5m`）动态增减剩余时间，无需繁琐弹窗。
- **性能自动节流**：
  - 当用户切换至「仅显示时钟（clockOnly）」或离开页面时，`requestAnimationFrame` 自动挂起，释放全部 Canvas 算力；开启律动时限制最大 `devicePixelRatio <= 1.75` 并复用 typed array 缓冲区，杜绝 GC 卡顿。
- **工具箱入口卡片同步更新**：
  - 同步精简工具箱列表页中「自习室」卡片的文案描述，使其与重构后的极简三预设白噪音、全屏时钟及双律动特性保持一致。
